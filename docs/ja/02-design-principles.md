# 設計原則

## 1. モデルはいつか誤判断する前提で設計する

指示への追従が常に完全であることを前提にしてはいけません。プロンプトインジェクション、曖昧な意図、幻覚、通常の実装ミスはすべて想定内の失敗形態です。安全性は、モデルとは独立した強制レイヤーによって実現します。

## 2. ポリシーと能力を分離する

フックが `rm -rf /` を禁止すると判断するのはポリシーです。一方、サンドボックスが `/` を書き込み不可にするのは能力制御です。両方を使います。ポリシーは意味的な精度を提供し、能力制御はポリシー / フック / モデルの失敗を封じ込めます。

## 3. 行動制御をセキュリティ境界にしない

[AGENTS.md](../../AGENTS.md)、CLAUDE.md、プロンプト、スキル、手順書、モデル生成計画はすべて行動制御として有効ですが、秘密情報、本番環境、保護ブランチを守る唯一の機構にしてはいけません。

## 4. フェイルクローズを優先する

セキュリティ上重要な強制はフェイルクローズを基本とします。フックのタイムアウト / 異常終了 / 不正出力後も処理を継続する製品では、そのフックを強制境界とみなしてはいけません。サンドボックス、IAM、サーバー側ポリシーで不変条件を守ります。

## 5. すべてのレイヤーで最小権限

必要最小限の権限だけを付与します。

- 組織全体ではなく対象リポジトリ単位
- 既定ブランチではなく機能ブランチ
- 不要ならクラウド API は読み取り専用
- 長期個人トークンではなくタスク限定の短期認証情報
- 無制限のインターネットではなく明示的な外向き通信先
- ホームディレクトリ全体ではなくワークスペースへの書き込み

## 6. 安全な自律経路を最適化する

成熟した Agent Harness は、すべてのシェルコマンドについて人間に質問するべきではありません。頻出する安全な操作は権限 / 規則とサンドボックスに組み込み、承認は境界越えや意味的リスクの高い操作に限定します。

## 7. サーバー側ポリシーを最終権威とする

エージェントが `main` に push しないよう依頼するだけでは不十分です。GitHub ルールセット / ブランチ保護 / 認証情報の適用範囲により、直接 push 自体を不可能にします。クラウド IAM、配備環境、本番データベースでも同様です。

## 8. 完了は条件として定義する

「完了」は会話上の自信ではなく、機械検証可能な条件とします。テスト、Git 状態、CI 状態、PR 状態、配備の根拠はモデルの記憶の外に置きます。実装例は [`completion_gate.sh`](../../reference/scripts/completion_gate.sh) を参照してください。

## 9. ベンダーアダプターは薄く保つ

各製品固有のフックを、次のような小さな内部契約に正規化します。

```json
{
  "event": "pre_tool_use",
  "tool": "exec",
  "input": {"command": "git push origin feature/x"},
  "context": {
    "session_id": "...",
    "cwd": "...",
    "repository": "...",
    "branch": "feature/x"
  }
}
```

中央のポリシーエンジンはベンダー非依存の判断を返し、Claude Code / Codex / Devin CLI のアダプターが製品固有スキーマに変換します。現行の Go 実装は [`internal/policy/policy.go`](../../internal/policy/policy.go)、ベンダー写像は [`internal/vendor/adapter.go`](../../internal/vendor/adapter.go) です。

## 10. ポリシー判断を観測可能にする

ポリシーバージョン、正規化された操作、判断、理由、承認主体、実行結果を記録します。秘密情報はログに残さず、タスク / セッション / ターン ID で相関できる構造化イベントとします。

## 11. 自律ループには上限を設ける

ターン数、経過時間、ツール呼出し、トークン / 計算費用、反復失敗に予算を設定します。停止フックや自己修復ループには遮断機構が必要です。

## 12. クラウド引継ぎは信頼境界の遷移として扱う

ローカルからクラウドへの引継ぎは、実行環境、認証情報、ネットワーク制御、データ所在が変化する境界です。ローカルポリシーがそのままクラウドに適用されると仮定せず、再認可します。
