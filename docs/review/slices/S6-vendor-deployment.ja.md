# S6 — ベンダー接続と配備具体化

## 主張

1. Claude Code、Codex、Devin CLIのライフサイクルイベントを共通ハーネスへ接続する。
2. ベンダー固有入力を共通モデルへ正規化し、同じ保証ロジックを利用する。
3. 本番参照配備で作業領域と信頼済みハーネス領域を分離する。
4. 認証情報侵害を起こり得る障害として扱い、Sandbox、短寿命・リポジトリ限定・最小権限IAM、GitHub側規則へ責任を分担する。

## 境界

- 前提: 接続対象となるS1〜S5の保証機構。
- 外部責任: Sandbox、IAM、SCMサーバー側規則。
- 対象外: 各ベンダー製品、Sandbox、IAM、GitHub Rulesetsの内部実装完全性。
