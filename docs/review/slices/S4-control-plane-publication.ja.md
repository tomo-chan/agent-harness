# S4 — 制御機構変更の公開審査

## 主張

1. 制御機構変更を編集手段ではなく公開されるGit差分から検出する。
2. 比較基準は確認済みGitHubリポジトリから直接取得した既定ブランチ先頭SHAとする。
3. 制御機構を含む公開には明示的な審査を要求する。

## 境界

- 前提: S1、S2、S3。
- 権威: GitHub既定ブランチ先頭SHA。
- 観測: 現在HEADとのGit差分。
- 対象外: GitHub側の最終認可規則、公開されないローカル編集の禁止。
