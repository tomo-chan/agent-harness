# S3 — 自律SCM公開制御

## 主張

1. 直接的SCM公開を狭い正規形に限定する。
2. `git push` は確認済みリポジトリ、現在ブランチ、実効push先、上流状態と整合する場合だけ自律許可する。
3. 強制pushを自律許可しない。
4. `gh pr create` を確認済みリポジトリと公開済み現在ブランチへ結び付ける。
5. 複合シェル等の正規形外操作を自律許可対象から外す。

## 境界

- 前提: S1、S2。
- 観測: ローカルGit状態とGitが解決した実効push URL。
- 対象外: フックから観測できない任意子プロセスの完全仲介、認証情報侵害後の外部権限封じ込め全体。
